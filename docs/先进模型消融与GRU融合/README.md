## 当前结论

MTKT的CIC在源模型有补弱线索，但三位置迁入GRU均未得到联合候选。时间输入T2I、当前解码T2D及输入／解码联合G3J形成四项主指标的非支配候选集合：T2I标准差更低，T2D极差更小，G3J总体／序列均值更高。T2I与G3J达到预设实质开发信号；[候选取舍](22_GRU候选的公平性取舍.md)同时报告个体退化，不能按单列最高选全面赢家。

LEFOKT源条件没有通过全部保护的方案，保留题目ID的加性替代仅以探索身份被选中。迁入GRU时，LAI输入／解码方案相对B0和同scale标量乘法均有联合点改善，但幅度小、弱于时间候选四项主指标；它的较大个体退化更少，仍有不同取舍。仅当前解码的LAQ两轮未通过。[匹配比较](24_LEFOKT加性迁移的匹配比较.md)区分B0、同scale乘法与三个非支配候选，且披露跨冻结批次限制。

各方向达到首个候选即记录暂停，无效方向按预登记上限结束。本轮没有自动追加seed／fold／Peiyou稳定性训练。上述是nips/fold0开发结果；正式all_results.json.windowauclate_mean缺失，不能用开发pooled替代。重复验证筛选存在选择偏差，配对区间不是确认性显著性或跨seed保证。时间特征来自DateAnswered并假设当前事件时刻已知，尚未验证作答开始前的可用性；LAI／LAQ不消费时间特征。
