# 模块选择与首批融合的判定规则

2026-11-15，MTKT时间模块严格评估已出现点联合线索后登记；其余模块严格结果未齐。因此这是探索性阶段的选择规则，不伪称在所有结果产生前预注册。原有联合保护、实质幅度和有限迭代规则不变。

## 源模型选择

1. 先核对重训完整模型和删除模块变体的严格题目目标完全对齐；不得用原生概念片段pooled与题目窗口直接相减。以“删除后模型为参照，加回模块为候选”评估方向。
2. 优先选择std/range同时下降且pooled/macro、固定弱10/20%、自身尾10/20%、固定强25%均值保护全部通过的模块；这是单seed点条件，不等于稳定性或因果唯一性。
3. 若同一模型多个模块达到点条件，以std和range相对改善两者中的较小值更大者优先，避免只靠极差一端拉动选择。报告其余Pareto选项和区间，不隐去保护失败项。
4. 若没有模块通过，则没有“已证明最公平模块”。可基于均值保护更完整、损害较小及明确机制，选一个最有希望的探索候选，明确称先验迁移假设，不把源模型极差较小当成GRU必然获益。
5. 每模型选择独立主方向。源模型从头训练时的剩余参数初始匹配，但删除CIC/交互因子也改变有效容量，不能把收益全部归到唯一子操作。

## 首批GRU融合

选定主模块后，从05接口表中登记至少三种结合位置/方式，并设必要匹配对照。ALiBi必须与同位置/同容量/关闭偏置的内容注意力比较；CIC点式控制存在核参数量差异，明确作为结构控制而非严格容量等同；时间输入/当前解码/门控历史有容量与放置差异，逐项记录。

仍用B0双GRU，nips/fold0/seed42，原训练选模/早停不改。第一轮从scale=.1开始，未达点候选最多再试.25/.5（CIC必要时采用更小.05而非.5，须在实际批次方案中预登记）；首个普通联合候选即记录暂停该方向，集中比较之后再稳定性验证。对照不算优化候选。

首轮共用同一基线并报告绝对指标和变化：验证题目窗口pooled、macro、std ddof0、range、固定/自身尾部、强组、退化数量/幅度、配对区间。正式windowauclate_mean没有做就明确缺失。

## 后续迭代

若无普通候选但出现保护较完整的补弱线索，下一版本针对具体失败项改进，例如融合位置、当前题条件或训练保护，不能无限扫同一个scale。旧UKT阶段已证明冻结/KL并不自动保护AUC，不能无依据机械重跑。每轮新版本先登记，实测后复盘。

新负载并发先按实际训练/窗口工作量匹配测量或明确有界试运行；峰值显存和cgroup硬限额留余量，吞吐/完成时间决定是否增并发。现有科学任务不为测量停止，校准选自然边界。9接口真实CUDA预检通过只证明链路可运行，不证明科学收益或并发最优。
