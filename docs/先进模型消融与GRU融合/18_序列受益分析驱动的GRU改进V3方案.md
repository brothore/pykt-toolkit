## 两条新结构，各最多两轮

|方向|机制及接入|参数与匹配参照|可证伪假设|
|---|---|---|---|
|G3J / time_input_decode|共享一份因果时间编码，分别经独立零初始化投影加入KC输入与题目GRU当前解码残差|输入scale=.5，解码固定为其.2倍，即.1；若无候选第二轮输入.25／解码.05；与B0及已完成T2I输入、T2D解码分别比较|状态更新与读出两条路径是否能共同补弱，或只是重复时间证据并增加干扰|
|G3S / time_sparse_input|沿用时间输入模块，以当前KC可观察的历史出现次数门控新增输入修正|gate=1/(1+平均log2重复次数类别)，scale=.5，若无候选再.25；可训练参数量与T2I相同；与B0及T2I scale=.5比较|限制对证据充分位置的改动，能否保留短／弱序列收益并减少强序列退化|

重复次数类别按现有CausalTimeEncoding计算：严格前缀中相同KC出现次数，round(log2(count+1))，多KC平均；不使用响应标签、UID、完整序列长短或真实AUC。初次遇到KC gate=1，覆盖越多gate越小。这个门控是新的归纳偏置，不能预先声称低覆盖就是低AUC成因；也不能保证当前群体收益必然随gate改善。

两方案的原始主干与新增输出均与对应B0初始化对齐，新增投影零初始化；所有原参数仍端到端训练，不声称隐藏状态冻结。共享时间编码并不意味着两条新增投影有相同优化作用。G3J有额外容量；若有效，必须同时比较已有单路径和参数差异，不独自归因于互补。

## 共同协议和边界

nips_task34/fold0/seed42、双独立GRU、batch32、emb256、dropout .3、Adam1e-4；原选模ΔAUC>1e-3、patience10、最多200epoch不变。开发题目窗口221348、primary773、std ddof=0；正式all_results.json.windowauclate_mean本批缺失，不用开发AUC替代。

每方向最多两轮，总上限4次新增训练；首个std/range同时改善且pooled/macro、固定弱10/20%、自身尾10/20%、固定强25%均值不下降的点候选记录并暂停该方向。实质开发信号仍要求std/range各相对下降≥1%且orirow配对Δstd95%区间上界<0；不是跨seed或正式测试显著性。新方案还要报告相对已完成T2I最佳候选的变化，避免仅对B0通过却没有进一步价值。

先真实32片段预检、有限梯度与零初始化一致性，再独占GPU完成本批两种负载的1/2/3并发固定工作量两次重复校准。与当前LEFOKT补充消融共享slot0；LEF未终止时新批共享并发上限1，不中断现有任务，不把其他负载结论当本批全局最优。
