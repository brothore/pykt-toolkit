# 匹配对照结论与下一步依据


三个CIC首轮相对同位置当前状态控制的Δstd分别为+0.0000189227、+0.0000695072、+0.0002395538，均未下降。题目与KC位置的微小均值增益同时伴随更大的强组增益；双分支CIC相对控制还损失pooled约0.00026427和macro约0.00033042。当前证据不支持新增直接历史访问改善序列均衡，也不能将双分支相对B0的总体收益独自归功于CIC时序机制。

LEFOKT查询／历史组合相对相同β=.5的历史结构，三轮均扩大极差（约+0.000922／+0.002304／+0.003226）；第三轮虽使std下降约0.00006407，却损害固定强组约0.00003198，仍无联合候选。没有足够依据继续叠加相同组合或只扫强度。
