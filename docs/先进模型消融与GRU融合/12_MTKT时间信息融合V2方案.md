# MTKT 时间信息迁入双GRU：V2 有界方案

2026-11-15，在CIC与查询/历史V1的21次新增训练全部结束后登记，开始本批前不使用本批结果。

## 为什么换机制

CIC题目/KC/双分支各三轮以及三条当前状态控制全部完成，零联合候选。全部12条新增结果的std都高于B0；部分总体AUC增益也见于当前状态控制，不能证明额外跨位置卷积有用。LEFOKT启发的9条新增训练也零联合候选；直接衰减历史题目通道通常损害弱组，不能继续假定历史去条件化适合GRU。

唯一接近的L1Q标量查询第二轮：std从0.0854331310412降至0.0853608630036，range从0.579344858963降至0.577040711497，但pooled从0.796528100282降至0.796521326669，故仍不达标。改善幅度很小，不追加同类scale扫描或稳定性复验。

源MTKT时间模块的严格匹配重训“加回”结果为Δpooled +0.002598217181、Δmacro +0.002524914305、Δstd −0.000051879531、Δrange −0.032883266312，固定弱10% +0.009208254183，固定强25% +0.001424481457，联合点条件通过但std区间跨0。这提供一个不同于后GRU局部卷积的、仍需验证的机制：时间间隔和练习覆盖可能帮助解释弱序列的状态变化。

## 方案与区别

时间特征仅用当前可观察的时间戳及严格前缀：同KC前次间隔、前一题间隔、同KC出现次数，分钟级log2离散编码；多KC平均。不访问当前真实响应，不使用orirow或测试AUC作为路由标签。

|方向|实现|待检验假设|轮次|
|---|---|---|---|
|T2I|time_input：时间编码零初始化投影后加到KC表示，进入历史响应编码与当前解码|状态更新缺少时间信息，而非隐藏状态缺少局部卷积|scale .1、.5，各从头训练|
|T2D|time_decode：时间编码与上一时刻题目GRU隐藏状态拼接，通过零初始化有界残差修正当前解码状态|保留历史状态，只按当前间隔调整读出可减少干扰|scale .1、.5，各从头训练|
|T2G|time_gate：以时间编码查询严格过去的题目/KC及响应表示，经门控残差修正题目GRU读出|同样的历史状态需要按时间证据检索，不只是统一衰减|scale .1、.5，各从头训练|

T2G不使用ALiBi；它同时增加时间查询、历史检索、门控，若有效须另做匹配消融，不能先归功于单项。T2I的时间编码也进入当前表示，不能解释为“只影响历史”。本批按题目窗口重新计算时间，源MTKT按概念展开，属于机制迁移而非逐层复刻。三方案新增输出均零初始化，真实容器预检要求初始预测与B0相同、两步梯度有限。
