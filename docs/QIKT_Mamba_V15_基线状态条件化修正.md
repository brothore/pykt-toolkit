# V15：让保护下的修正读取基线状态

2026-11-09登记，先方案、再实现和预检、最后条件执行。V7已完成的置信度/头分歧固定门控均未通过联合条件；I4R2有小幅联合收益，但修正MLP只读取题目embedding与手工历史，并不知道主干已经预测了什么。这是可检验的表示缺口，尚不是确认的失败原因。

新假设：同一历史证据在主干已充分解释和明显未解释的位置应产生不同修正。把冻结预测作为输入，可同时学习修正的方向与幅度；固定门控只能缩放已有修正，两者不同。与全序列统一偏置不同，这些输入随当前题和历史变化，可以改变序列内排序。额外容量也可能过拟合，不能预先宣称优于固定门控。

共同使用原B42冻结主干，重新初始化小分支，不续训I4R2。nips_task34/QIKT-Mamba/public_mamba/fold0/seed42，batch32，scale=.5，KL=1，原采样、选模、早停不变。原baseline训练14/选中4；复用I4R2（17/7）作组件匹配参照，不算新增实验。

输入增加6维：三个冻结预测头概率、sigmoid(组合baseline logit)、三个头的极差、组合概率的4p(1−p)。全部detach，不含UID、当前/未来响应、真实序列AUC或验证标签。头概率由原生严格因果路径计算。
