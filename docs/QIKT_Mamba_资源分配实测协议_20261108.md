# 服务器资源分配实测协议

登记于性能结果产生前。V3已自然完成；不停止其他任务，不更改科学实验权重。

固定环境：NVIDIA A10、现有pykt-qikt环境、nips_task34、QIKT-Mamba/public_mamba基线已选权重、FP32、batch32、长度200、每worker CPU线程2、DataLoader workers0。记录实际GPU/驱动、源码/数据/权重校验与运行命令。测试使用临时内存中模型副本，不输出科学指标、不覆盖原权重。

分别测试普通训练（原损失/Adam）、排序训练（alpha=.02、rank=.0005）、窗口推理（eval/no_grad）。各档覆盖同一组120个确定性batch，训练数据只来自训练折，推理用验证折；训练batch固定seed42洗牌，窗口batch覆盖验证窗口位置。并发c时各worker按轮转分摊相同120个batch；每worker先做6步预热，预热/模型加载不计入稳态计时但单独记录端到端时间及开销。不同档的临时优化器轨迹不同，测试衡量同类工作成本，不评价模型质量。

并发按1、2、3、4尝试；只有前档无明显吞吐恶化且峰值预算允许时继续6、8。两次连续新增档位使吞吐较当前最佳低至少5%时不再增加该工作类型的并发。高并发需满足上一档单worker测得峰值的保守外推加至少3GiB余量，小于总显存，并保留主存余量；不可用GPU瞬时利用率禁止或允许。各已测档至少两轮，潜在最佳与相邻档的差异≤5%时偏向更低并发并报告近似平台区间，不宣称全局唯一最优。

每轮稳态计时以所有worker预热完成后共享释放时刻起，直到最后一个worker CUDA同步完成。报告总step/s、有效计分位置/s、单worker时间、总端到端耗时、预热与加载开销、CUDA allocator峰值allocated/reserved；另以约0.5秒采样设备利用率/显存、主存、CPU和I/O。采样设备峰值不称为连续真实峰值；allocator峰值不含所有外部CUDA开销。训练和推理单位不同，不混为一个效率排名。

另测60步普通训练＋60步窗口推理：顺序执行为参照，与二者并行各一worker比较，工作量保持，单独报告端到端与稳态。两个阶段的吞吐不能直接相加当成同类samples/s。

所有测试通过tsp管理，独立cell输出和日志，完成一个测量单元即原子保存；停止请求在step边界退出，保留已完成单元。恢复核对身份后复用已完成单元；中断单元从该单元开头重测，不冒称优化器精确续训。只对成功、完整、身份一致的单元做排名。开始测试及各测量单元启动前核查队列外GPU进程；有外部负载则记录并停止新增测量，不杀任何外部进程。

结果用于配置下一批新任务的阶段预算；不永久固定并发。若120步计时不足以稳定估计或结果波动大，报告限制，先针对最佳及邻档追加预登记的等量复测，不进行无界搜索。全部结果放logs/resource_calibration_20261108，不上传Git。
