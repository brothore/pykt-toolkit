# 06：统一复盘、因果缺口与后续路线

本页是文档整理后的研究建议清单；**没有把这些建议当作已执行实验，也没有在本次整理中提交新的训练任务。** 当前34轮均已完成，无联合候选。具体指标和失败条件见03–05的完整表。

## 观察与解释分开

|机制|已完成观察|当前可以判断|仍不能判断|
|---|---|---|---|
|普通历史检索/W2|R0–R3、S3均无联合候选|这些外挂读出实现未达到目标|W2在GRU内部状态/门控位置是否有用|
|UKT协方差与alpha²|固定UKT权重推理替换后下降|现有权重依赖原计算|重新训练后的模块必要性及GRU可迁移性|
|乘法Rasch|S1有小幅补弱，C0加法控制也接近|不能把S1收益归为乘法独有|同预算下更好融合是否存在|
|只改当前解码|Q0均值扰动较小，std变化小、极差常不降|缩小放置范围可减小扰动，但效果不足|是否需同时保留不同尺度历史信息|
|冻结主干|S2/S3仍会损害排序/总体|权重冻结不等于预测保护|合适的分支路由能否减少干扰|
|KL及排序保护|A0/A1没有联合候选，A1/R3只剩pooled保护失败|约束未保证全面保护|缺匹配warm-start控制，不能孤立归因给KL|
|序列均衡目标|本批保持原选模/早停与主体任务|不能靠总体AUC单列判断成功|需要训练关注/排序目标时，应另设新版本而非回写本批|

C0并非可忽略的“无效对照”：它改变了对S1的解释，提示额外参数/优化路径可能已能产生类似补弱，必须先排除这一点再称UKT机制迁移成功。

## 尚缺的关键实验与优先级

|优先级|建议实验|目的/匹配对照|状态|
|---|---|---|---|
|高|W0：同Q0结构、从B0开始、KL=0/pair=0|与A0的初始化/训练路径匹配，识别约束增量；同数据/seed/lr/scale|尚未执行|
|高|UKT保留题目ID的加性替代重训|去Rasch不能同时去掉题目ID；与完整UKT同预算|尚未执行|
|高|题目分支/KC分支分别删除后重训baseline|确认当前双GRU的信息来源和融合依赖，保持其余协议|尚未执行|
|中|UKT均值距离、协方差传播、距离调制匹配重训|将现有推理敏感性升级为训练消融证据|尚未执行|
|中|分支专属小适配＋受控融合|题目/KC分支分别试，配同容量和融合控制，不一次叠加|新假设，尚未执行|
|后续|对比学习开/关独立对照|原UKT use_CL=0，不能用于解释原有优势|新假设，尚未执行|
|后续|均值/协方差进入GRU状态或门控|区别于已失败的外挂读出，需正方差与数值稳定预检|新假设，尚未执行|

先明确实验与匹配对照，再预登记轮次上限和保护条件；无效方向最多2–3轮，初步候选记录暂停，稳定性/Peiyou后置。不继续无限扫描已经结束方向的系数；跨模型正式测试只作已披露诊断，不把测试orirow或整条标签特征用作训练路由。

## 可靠性与报告仍欠什么

开发验证与正式windowauclate_mean不同；当前后者缺失。尚无跨seed/fold复现和Peiyou迁移。orirow重采样不是独立学生保证；std改善不能取代极差和大退化数。需要补充控制的组合不得做单模块因果归因。没有观察到联合候选，不等于证明所有相关机制都无效。

## 旧Mamba档案的归属

旧方向已按用户要求停止接续。它包含序列均衡/排序、低频覆盖、检索、多尺度补充、冻结/保护、固定融合等历史实验；其baseline、协议和部分实现不同，不计入当前34轮，也不直接并入GRU消融表。若借用旧机制，必须标明历史尝试，并在新GRU上设置匹配对照。
