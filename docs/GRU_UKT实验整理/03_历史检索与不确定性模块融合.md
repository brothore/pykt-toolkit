# 03：历史检索、不确定性与冻结读出融合实验

本页为2026-11-14已完成结果快照。统一比较条件：nips_task34、双独立GRU、fold0、seed42；原B0训练27 epoch/选中17。验证窗口221348条题目预测，主子集773条orirow（有效计分≥20且少数类≥5），标准差ddof=0。pooled是交互合并AUC，macro是序列AUC等权平均；本页两者均为开发验证指标。**正式`all_results.json.windowauclate_mean`缺失，未完成正式测试或跨seed稳定性验证。**

固定弱10/20%及强25%均按原B0定义，自身尾部随模型重新排序。所有Δ为候选减B0。每列最佳值加粗；单列最佳不代表联合有效。原选模/早停规则未改，各行保留实际完成/选中epoch。

## 设计与完成情况

本页15轮：R0/R1/R2/R3各3轮，S3再3轮。R0是普通均值距离历史检索控制；R1引入学习协方差的W2与alpha²传播；R2在R1上根据检索不确定性收缩幅度；R3在R1上加入原UKT乘性距离调制。都保留双GRU，在预测logit旁附加零初始化、有界修正，端到端训练。前三轮scale=.1/.25/.5、lr1e-4。S3从B0开始冻结原主干，仅训练W2读出，scale同前三轮但lr=.001。检索只读取严格过去响应，当前/未来标签不进入预测。

R0/R1比较受有效参数量差异影响；R1/S3还改变了初始化、主干训练和lr，不是纯冻结消融。

## 复盘

15轮均无联合候选。W2在原UKT中敏感，不代表外挂到GRU有效；普通检索R0也未成功，因此不能把失败全部归因给不确定性数值。S3/R3的std/range均改善且弱组有收益，但pooled下降约.002589、强组下降约.000950，冻结没有实现预测保护。可能是读出信息冗余、融合方式或目标不对齐；尚不能证明W2在GRU内部状态或门控位置无效。
