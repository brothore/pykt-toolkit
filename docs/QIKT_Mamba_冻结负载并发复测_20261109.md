# 当前冻结负载并发复测

2026-11-09登记。双任务试运行已实际开始，GPU约94–100%，但这不能证明总吞吐最优；旧完整主干的单并发推荐也不能代替本次冻结结构的实测。

等V6/V7/V11现有任务自然终止、GPU上下文全部退出后，使用已经完整评估过的首轮checkpoint，独立复测两种结构：V11 T0冻结检索分支、V6 I4冻结多尺度＋额外KL前向。任一轮产物不存在或权重校验不匹配就明确失败，不冒称前置成功；当前任务不停止、不重启、不迁移。

每种结构分别测训练与窗口推理，并发1/2/3，每档两次。总工作量固定120个batch、batch32、长度200、每worker 6步warmup；各并发均分同一全局工作量，原生精度与loss保持。不保存这些一次性性能测量的科学模型权重，不用它们选研究超参数。

按总step/计分位置吞吐、完成时间和启动开销比较，记录GPU、allocator和容器硬限额余量；选在最高中位吞吐5%内的最低并发。每worker主存估计2GiB、额外保留4GiB；预算不允许的档位明确跳过，不把未测3并发称为已测。两档连续明显变慢时有界停止扩张。

训练样本是固定seed置乱的同一数据切片，不是原SequentialSampler完整epoch证明；两种结构及训练/推理不互换结论。本次不穷尽batch size或所有模型。不同阶段叠加、GPU平均利用率和显存占满都不能独立证明提速。

工具通过tsp预排，根目录logs/resource_calibration_frozen_20261109。按完整测量cell保存，可复用已完成cell；中断单元重测，不称优化器断点续训。新出现未登记GPU上下文时只停止自己的测量子进程、保留现场，不停止无关任务。
