# 学生模拟：目标函数与多任务学习方案

更新日期：2026-10-25。当前分支：`feat/student-state-simulator`。

## 1. 讨论边界与目标

- 本文记录方案讨论阶段。之后用户授权实现首步行为和作答过程子方案，其进展分别见 [DKT 首步行为实验](DKT_首步行为_三轮闭环实验.md) 与 [DKT 作答过程实验](DKT_作答过程_四轮闭环实验.md)；其他候选没有据此自动实施。
- 后续实现应使用独立模型/训练入口及独立数据产物，保持现有 DKT 和其他模型的训练行为。
- 优先探索固定模型结构、改变目标函数；若引入训练期辅助输出头，应明确说明其参数开销，不能称为“完全不改结构”。
- 主要结果指标是对应实验 `all_results.json` 中的 `windowauclate_mean`；不能用其他 AUC 字段代替。
- 保留验证集选模和早停规则；测试集不用于选择辅助目标、阈值或 loss 权重。
- “更准确建模学生”还需要分知识点表现预测、概率校准、多步模拟等诊断，不等于给隐状态添加心理学名称。

## 2. 预测与模拟的关系

给定题目序列，现有自回归 KT 可以定义回答轨迹的概率：

\[
P_\theta(r_{1:T}\mid q_{1:T})
=\prod_t P_\theta(r_t\mid H_{t-1},q_t).
\]

其负对数似然就是逐步 BCE。因此 BCE 本身已有回答轨迹的生成式解释，现有 DKT 也可以采样回答、回填历史并继续模拟。新的目标函数应约束原目标没有直接强调的学生画像、行为统计或长期模拟能力。

对固定课程的回答模拟，不自动构成“换一种课程会提高学习效果”的因果证据；实际题目安排可能依赖老师、平台和学生先前表现。

## 3. 已讨论的六类方向

| 方向 | 目标 | 只改 loss 是否足够 | 主要限制 |
|---|---|---|---|
| 多任务学生表征 | 一个状态解释答对率、分知识点表现、练习分布 | 部分可以；现有 DKT 各知识点概率可直接用于表现监督，题目分布通常要新头 | 辅助任务可能学到课程顺序等混淆信息 |
| 知识与作答行为分解 | 区分掌握、难度、短期失误/猜测 | 显式分解需要额外参数、结构或假设 | 二元回答不能唯一识别真实粗心和猜测 |
| 个体差异 | 学习速度、初始水平、稳定性、遗忘倾向 | 学生均衡和轨迹损失可以只改 loss；显式个体参数需要扩展 | 测试学生未见过，不能仅记忆训练学生 ID |
| 生成式状态空间 | 显式学习随机状态转移和回答生成 | 新状态空间需要结构变化；现有 DKT 的闭环目标不需要新网络 | 复杂度和长程模拟误差较大 |
| 轨迹级训练 | 多时间尺度表现、连续错误及恢复模式 | 可以 | 不能强制所有知识点单调增长等不成立规律 |
| 学生与教学策略联合建模 | 区分学生作答与题目分配 | 通常需要额外输出或分支 | 题目选择不一定代表学生偏好 |

### 3.1 知识与行为分解的示意

\[
P(\text{答对})=g+(1-s-g)P(\text{具备解题能力}).
\]

这里的 `s`、`g` 只能视为受约束的候选失误/猜测隐变量，不能直接当成有真实标注的心理状态。不能把“当前模型高概率预测答对，但实际答错”直接标记为真实粗心。

### 3.2 个体差异的示意

从已观察的历史前缀推断学生特征，再影响状态更新；应能适用于未见过的新学生。只有“每个学生一个可训练 ID 向量”不满足当前学生隔离测试的要求。

## 4. 固定结构、直接改变目标函数的候选

### 4.1 未来分知识点表现损失 `L_profile`

DKT 已输出当前时刻各知识点的答对概率 `p_t(c)`。用后续短窗口内该知识点的实际正确率 `a_future(t,c)` 监督它：

\[
L_{profile}=\sum_{t,c}w_{t,c}\left(p_t(c)-a^{future}_{t,c}\right)^2.
\]

- 没出现的知识点必须掩码，不得当成正确率 0。
- 低样本目标降低权重；窗口不宜过长，避免将后续学习效果强行归因于当前状态。
- 多知识点展开的一次回答不能当成多次独立作答；按原始事件形成目标或加权。
- 未来回答只能作为训练标签，不能进入当前预测状态。

### 4.2 闭环多步预测损失 `L_rollout`

普通 teacher forcing 在预测第二步时读取第一步真实答案。闭环目标应对第一步可能答案积分：

\[
\widetilde p_{t+2}
=p_{t+1}p^{(r_{t+1}=1)}_{t+2}
+(1-p_{t+1})p^{(r_{t+1}=0)}_{t+2}.
\]

用真实第二步回答监督该边缘概率。两步可以精确展开、保持可微；长距离的精确展开复杂度指数增长。不同于简单重复或累加已有 teacher-forced BCE，该目标不读取真实中间回答。

### 4.3 可观察行为事件损失 `L_event`

用现有模型的闭环分支计算连续答错、错误恢复、短窗口错误数等事件概率，再对照真实轨迹。它描述可观察模式，不将它们等同于粗心、焦虑或注意力等心理原因。

### 4.4 学生均衡和校准对照

- 学生均衡：调整不同学生、长短序列和活跃程度的损失贡献，不新增学生 ID 输入。
- 校准：可以将 Brier score 作为对照。BCE 本身也是适当评分规则；添加 Brier 不保证自动改善校准或 AUC。
- 辅助目标的标签和均衡权重只能来自对应训练折，不能从验证/测试集估计。

### 4.5 最小消融组合

1. 原始 BCE。
2. BCE + `L_profile`。
3. BCE + `L_rollout`。
4. BCE + `L_profile` + `L_rollout`。

各组固定 backbone、参数量、fold、seed 和训练预算；保持相同验证集选模规则，并报告 `windowauclate_mean`。这一组合尚未实现或运行，不预设一定优于基线。

已完成三个本地原始数据集的全量聚合审计，详见 [原始监督信号与多任务候选](学生模拟_原始监督信号与多任务候选.md) 和 [统计记录](原始数据监督信号审计_20261025.json)。

- 培优 `ans_state` 与正误等价，不是新监督；题目内容、解析和知识层级则确实存在。
- 新文档进一步区分了严格只改学生 loss、训练期增加辅助头、以及扩展推理结构三种路线，并记录了事件对齐、时间粒度和标签泄漏限制。

## 6. 参考与关系

- [AT-DKT: Enhancing Deep Knowledge Tracing with Auxiliary Tasks](https://arxiv.org/abs/2302.07942)：题目标注与个体历史表现辅助任务。本文讨论的“多任务有潜力”有相关研究基础，但不声称在本项目已验证改进。
- [Properties of the Bayesian Knowledge Tracing Model](https://jedm.educationaldatamining.org/index.php/JEDM/article/view/35)：BKT 状态和参数的性质。失误、猜测等隐变量的解释需要模型假设和额外证据。
