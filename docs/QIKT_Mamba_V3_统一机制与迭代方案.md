# V3：可靠补弱、限制增益分散的统一研究方案

登记日期：2026-11-08。先登记后执行；V1/V2及方案07/08不回写。

## 统一判断

目标是让弱序列获得更多可学习的排序增益，并控制增益方差，而非只提高pooled AUC。已有分解表明，负的baseline-AUC/增益协方差必须足够抵消增益方差，std才会下降。极差还受少量端点配对支配，不能单独据其缩小宣布成功。

有用线索：温和低频覆盖；同序列排序作为小强度辅助；当前题偏差修正；相关历史覆盖；有总体能力的主体加少量补充分数。证据不足或存在反例：强排序、以高BCE替代可靠排序缺口、强KL与margin保护、仅扩大历史上下文。它们不是被永久否定，而是当前不宜作为强干预主线。

## 评估前置条件

首先穷尽核验nips fold0验证集：调用原生generate_window_sequences、KTQueDataset、evaluate，与既有窗口覆盖、输入张量和实际预测比较；按UID分片保存进度，失败即关闭后续评估准入。

当前原生QIKT题目级loader将通用question-window loader置None，通用late-fusion脚本不是直接可用的QIKT路径。本核验明确验证其受支持的原生题目级预测路径，不能冒称运行了未修改的通用late-fusion脚本。正式windowauclate_mean仍需明确数据分区和适配路径后单独确认，不能将验证pooled改名。

核验修订记录（完整核验前登记）：首次任务34在第3个16-UID分片因AUC精确阈值1e-10失败，输入张量全部匹配、预测最大差1.1924e-7，而AUC差约−5.8685e-8。该现象与分片批次变化导致的浮点近邻排序差一致，具体来源尚未单因素定位，不能称为完全一致。保留首次失败，另建核验R2：仍穷尽输入精确一致，预测最大误差≤1e-6，并保存原生逐预测；全折pooled差≤1e-6、std差≤1e-5、range差≤1e-4才准入本版本的大幅信号筛选。实际差值与exact_metric_parity逐项报告。预算不是有效性门槛，不能拿它认证旧版微小收益；若超预算则阻止评估。它远小于本版本std/range各1%的目标尺度。

训练可与上述只读核验并行，但新方案进入窗口评估前必须等待核验成功；失败的前置不得当作成功。原训练选模及早停不变，不用测试标签开发。
