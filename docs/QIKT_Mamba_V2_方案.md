# QIKT-Mamba V2：补足可弥补缺口，降低序列间差异

状态：方案先行，尚无 V2 收益结论。V1 已独立封存于 `/data/pykt-toolkit-records/qikt_switch/V1_20261105`，不能用 V2 方案回填 V1 历史。本方案发布后才启动 V2 实验；每次修改新增 revision 和原因。

## 1. 目标与 V1 经验

核心目标是 orirow AUC 标准差（ddof=0）和极差共同下降，同时保住整体、序列平均、原有强项与尾部表现。所谓“公平性”仅指本研究的序列表现均衡，不涉及人口属性公平的结论。

V1 的总体提升不等于目标实现。nips 的 overlap 在三个 seed 验证集都降低极差但提高标准差；排序、dropout 和固定混合的双降不稳定；peiyou overlap 虽双降，仍有大量逐序列退化。冻结主干和 KL 也没有自动保护排序。因此 V2 不再把所有弱序列归因为切换，也不以最优 pooled AUC 决定方案优劣。

基本关系：`Var(A+Δ)-Var(A)=2Cov(A,Δ)+Var(Δ)`。需要可靠地让较弱序列获益更多，且避免新退化；压低强序列缩小分散不合格。极差可能更换端点，需实际复算，并检查端点敏感性，不能只比较固定两条序列。

## 2. 数据边界与固定对照

- 首轮仍为 nips_task34、fold0、seed42；基线/候选同数据、初始化种子、原生 batch32、emb256、public_mamba、Adam lr1e-4、max200。
- 原生验证 AUC 超过最优值 .001 才更新、10 epoch 早停的逻辑保持不变。本方案不暗改训练选模为公平性指标；训练后再按多指标比较方案。
- V1 已有 seed42/43/44 基线和源代码/权重；V2 首轮新建相同协议基线校验，以排除新损失接入或恢复器改变默认行为。可复用身份验证一致的 V1 基线权重/预测作对照，不能把跳过基线重训藏起来。
- 新候选只在训练折学习；fold0 仅用于开发/选方案。禁止按验证/测试 UID 的真实 AUC给训练样本加权或在推理时选专家。测试不参与困难定义、阈值、路由和混合系数拟合。
- V1 的测试标签/结果已经观察，V2 在相同测试集上只能称为重复使用的确认，不能声称独立盲测。未见 seed 可检验优化波动，但不能产生新的独立数据证据；若需要强泛化结论，另需事先固定的新留出数据。
- seed42 首轮通过后再对43/44做配对验证复验；nips 有一致支持后，固定方案和参数才进入 peiyou。不根据 Peiyou 测试重新调 nips 参数。

## 3. 衡量“补弱且保强”

统一输出 `all_two_class`、`primary_20_5`、`strict_50_10` 三种统计子集；primary 的标准差/极差是方案主比较，另外两组用于敏感性分析。不能通过删除困难序列改善指标。

| 维度 | 必须记录 | 防止的误判 |
|---|---|---|
| 整体 | 正式 `windowauclate_mean`；开发用 `validation_window_auc` | 不能把验证值替代正式主要指标 |
| 平均 | orirow macro AUC | pooled 提升掩盖大多数序列下降 |
| 分散 | std(ddof=0)、range、q95−q05、端点 UID/长度/两类数 | 仅压低强项或极端短行驱动收窄 |
| 尾部 | 每个模型自身最差10%/20%均值 | 忽略实际新尾部 |
| 固定弱项 | 基线固定最差10%/20%的配对均值和退化数 | 尾部成员更换制造假改善 |
| 原有强项 | 基线最高25%均值、退化数、最差delta | 补弱以牺牲强项为代价 |
| 个体退化 | improved/worsened/tied、下降超过.001/.005/.01的数量、最差delta | 仅报告平均收益 |
| 不确定性 | orirow配对重采样的ΔAUC、Δstd、macro/尾部/强项Δ；极差原值与删一端点敏感性 | 将微小点估计当作可靠改进 |
| 可复现 | 各seed单独变化、均值与方向一致性 | 用平均抵消失败seed |
| 计算成本 | epochs、选中epoch、optimizer steps、训练/推理时长、参数、显存峰值 | 相同epoch冒充相同计算预算 |

默认退化容忍界限为0，不自行放宽。区分两个标志：

1. **开发候选**：std和range均下降；pooled、macro、基线固定弱尾部、自身尾部与高分组的均值点估计不下降。只是允许继续验证，不等于保护了每条序列。
2. **严格目标通过**：上述要求成立且逐序列退化数为0；不确定性、跨seed和测试证据同时公开。达不到就记录失败/部分改善，不宣称解决。

置信区间跨0表示证据不足，不能称为已证明不下降。不用未经用户确认的非劣效界限替代0；`.001/.005/.01`只用于报告退化幅度，不用于放宽验收。大量候选后的区间属于探索性证据。

## 4. 诊断：低 AUC 与可学习缺口分开

训练折统计题目/KC频次；仅当前题与历史前缀构造相关练习支持、已见题比例、KC覆盖/交错、历史长度和间隔。完整序列正确率、切换率、基线真实 AUC仅作事后解释，不能直接作为推理路由特征。

按以下维度检查固定弱序列和强序列：短历史/少相关练习、低频题/KC、低正确率、知识点交错、长序列、题目构成、多seed稳定低分/高波动、简单参照能改善而主模型落后。报告交叉群体，训练支持少于50条orirow的细群体只探索、不单独强加权。

简单参照的题目/KC先验只在训练折估计；验证前缀记忆在预测时仅用过去答案。参照收益是潜在缺口证据，不是保证能学习的上限。按标签统计的条件分析不能替代原始std/range。

困难权重若依赖基线预测，必须来自训练折内部OOF；外层fold0完全排除在教师训练中。不能直接用在同一训练行拟合的教师残差伪装OOF；没有合规OOF时先用均衡/覆盖方案，不启用“可靠困难”加权。

## 5. 七类方案与逐轮策略

### A1：真正按完整 orirow 等权的 BCE

假设：原 token 平均目标让长序列占据更多关注。先改变损失权重，保持模型、样本集合和训练更新次数不变。

设训练切片数W、有效orirow数U、完整训练orirow i的计分目标数N_i。均匀抽取切片时，等序列目标用 `(W/U) × mean_batch[sum_valid BCE / N_uid]`；不能把每个200片段平均叫作整条序列等权。所有原有有效输出头采用同样归约，保留其权重。

- R1：`L=.75 L_native+.25 L_sequence`。
- R2：R1若标准差/极差方向均改善且保护项不下降，混合系数提高到.5；否则降到.1，检查是否过度关注短序列/噪声。
- R3：只有前两轮至少有可解释的部分改善，才比较纯等权或与A2组合；无支持则停止该分支。
- 对照：alpha0必须与原loss/梯度一致；同一UID拆成多片不能改变它的总目标权重。拒绝训练增强改变目标集合而N_i仍未更新。

### A2：序列等权与序列内部排序对齐

假设：BCE均衡未必改善同一orirow内正负排序。排序项保留全部原BCE，单类别序列只贡献BCE。

- R1：A1的温和目标 + .01 的片段内pairwise，按UID/计分覆盖校正片段权重；明确它不是完整orirow AUC的无偏替代。
- R2：若内部排序改善但保护受损则降到.002；若两项分散改善且保护通过则试.05。只改排序权重。
- R3：仅在片段代理有证据时，比较同UID多片打包的跨片正负对；限制pair数，保存采样器状态，不跨UID配对，不保存过期分数冒充双边梯度。

### A3：有界困难/群体鲁棒目标

假设：均值目标仍忽略系统性薄弱群体。高BCE与低AUC必须分开诊断。

- R1：序列损失的平滑指数倾斜（TERM思路），温度t=.5、原目标混合占比.75、权重上限2；稳定logsumexp，避免单个异常主导。
- R2：若改善由长尾噪声主导则温度减半；若可靠弱群体受益且保护成立，比较预定义前缀/覆盖群体的Group-DRO式EMA权重，更新率.01、权重上限2、原目标占比.75。
- R3：只有合规训练OOF齐备，才引入可靠困难分数：跨seed一致缺口×类支持可靠度，权重上限3。不能按fold0低AUC行给训练权重。
- TERM/Group DRO约束的是损失分布，不自动保证AUC方差或极差；受限变体不宣称严格复现原论文。

### B1：低频题/KC覆盖均衡

假设：部分弱序列缺训练覆盖。只用训练频次和当前题KCs，分开困难与异常。

- R1：频次逆幂.25，最大相对权重2，和原目标混合系数.25；用数据集全局归一化，不让每个batch随机归一化改变定义。
- R2：若稀有群体获益且常见群体稳定，提高混合到.5；若噪声/常见群体退化则降到.1、上限1.5。
- R3：只比较支持充分的“短前缀×低频KC”等组合群体；没有样本支持不扩展交叉权重。
- 先用loss权重隔离目标效应，再考虑采样；重采样必须另报更新次数和计算预算。

### B2：相关历史不足的条件化补充分支

假设：V1全局线性记忆残差过于粗糙，不能区分证据充分程度与当前题要求。

- R1：基线冻结；当前题表示 + 因果KC后验/支持/回访间隔/覆盖特征，16维小MLP，零输出初始化，logit修正上限.05。
- R2：按支持不足/充分群体复盘；若确有可弥补缺口但容量不足，只放开小投影、lr1e-4并加KL锚，不全量改主干。
- R3：只在明确相关历史缺失时比较短/同KC/长历史三尺度特征；每次加入一个来源，保留消融。
- 推理只能看当前题和过去，不用当前/未来答案、UID真实AUC或测试群体标签。参数冻结、小残差不是AUC保护保证。

### C1：基线锚定与排序保护

假设：补弱更新会破坏原本正确的排序；仅全局KL不够。

- R1：保留冻结基线，零初始化有界小分支；训练中对教师已正确且margin>.1的同序列正负对加排序保持约束，同时允许修正原错误对。先用全局KL=1，分支上限.05。
- R2：若未学到缺口且漂移过小，只把KL改为.1；若强项受损则提高保护系数或减小上限，不同时改变两项。
- R3：与证据最清楚的A1/A2/B2单项组合，并保留单项对照。教师的训练内正确不等于泛化正确；优先使用OOF可靠对，未具备时明确限制。

### C2：可用前缀决定的互补性融合

假设：不同能力对不同可观测条件互补，而非每条序列都需要同一个模型。

- R1：先比较已冻结的固定平均，不能按test真实AUC选专家。
- R2：仅在诊断有互补性时，用当前题/历史支持训练小gate；通过训练内OOF拟合，权重限制在固定平均±.1，保留基线概率下限。
- R3：只有gate跨seed稳定且保护成立，才扩大范围；否则固定平均或停止。整序列统一单调变换不作为改善序列AUC的方案。

## 6. 执行顺序和有界迭代

先A1，再A2；同时进行只读CPU缺口诊断。随后根据诊断安排B1/B2，最后A3/C1/C2；高成本OOF和专家只有前置证据充分才启动。每个家庭先R1、再按预定义规则R2，R3有明确前置条件；不进行无界网格搜索。

每轮先落盘 `protocol.json`（假设、唯一改动、对照、输入、seed、指标、预算、后续决策）；执行后保存结果、失败/退化解释和下一轮唯一改动。整个家庭的结论至少包括：验证是否双降、保护是否失败、哪些序列/群体驱动、成本、跨seed支持、停止/继续理由。

先比较公平性Pareto集合，再看总体性能约束。不能因pooled AUC增益最大就跳过更均衡方案；也不能选std下降但range恶化或靠强项下降收窄的方案。

训练、预测、比较均复用V1已验证恢复/队列机制；默认单GPU一个计算任务，CPU独立诊断/汇总并行。已确定的有限后续工作提前排队；条件分支由保存的结果自动判断，不需要Codex在线才能衔接。失败/停止或输入改变时停在对应阶段，不盲目重启。
