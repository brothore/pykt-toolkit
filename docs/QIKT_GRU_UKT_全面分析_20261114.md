## 从观察到可检验机制

1. 七模型序列难易排序高度一致；稀有题/KC与平均表现的直接关联弱，不能默认低频就是病因。UKT相对收益组也可能有长度/正确率等混杂，上表不证明不确定性成因。
2. UKT把KC/响应表示为均值与对角协方差，W2²=||mu_i−mu_j||²+||sqrt(v_i)−sqrt(v_j)||²。多头严格过去检索，值均值用alpha，值协方差用alpha²聚合；这是值得做均值对照的具体结构。
3. 实际UKT使用题目难度向量调制KC表示，但QIKT已有题目ID与KC条件输入，新增Rasch是否有独立收益需要匹配消融；不先同时添加所有模块。
4. UKT的乘性距离调制乘在负距离分数上：效果减小时分数反而更接近0，不等同于普通的负时间偏置。因此R3单独检查原实现设计，而非先验称遗忘有效。
5. use_CL=0使对比学习/uncertainty augmentation不进入该已存训练目标。CL可作为后续新假设，不能当作解释现有优势的模块。

## 迁移实现与因果边界

新实现保留题目/KC两GRU与原an_irt多头任务；可独立关闭的UKTReadout直接读取题目embedding和平均KC embedding，当前题只检索严格过去响应。正协方差ELU+1+epsilon；无历史/padding注意力为0，协方差平方根设下限避免sqrt(0)产生无穷梯度；零初始化有界修正避免一开始改动预测。

- R0：均值距离＋固定单位协方差，判断普通检索是否已足够。
- R1：学习协方差的W2检索和协方差传播，判断分布表示增量。
- R2：R1的修正按检索协方差收缩，比较附加融合和不确定性控制融合。
- R3：R1＋UKT原乘性距离调制，检查该设计而非仅名称。

这些是UKT启发的受控迁移，不是完整UKT复现；多KC采用QIKT侧的平均KC输入，UKT原报告含KC展开/题目融合。R0/R1协方差有效参数不同，跨seed和超参差异没有消除，不把单轮结果归因给单个模块。

14项CPU检查覆盖GRU别名、原生模型工厂、W2公式、严格因果、alpha²协方差、padding有限梯度、零修正一致性、完整epoch恢复与调度失败语义；真实32条训练片段CUDA预检和新GRU负载并发实测已作为训练前置排队，不冒称已通过。
