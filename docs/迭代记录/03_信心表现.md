# 信心与表现联合建模：逐轮补充记录

数据集 `nips_task34`，fold 0，seed 42，学生/模型最多 20 epoch。独立文件按已有 JSON 和模型目录核对，选定版本 `r2_ordinal`；测试指标不参与改选。

## 每轮观察与配置

### 第 1 轮：五档信心分类

置信度 0 有效，缺失掩码；五档分类偏向 100，主任务未超过基线。

关键配置：`{"confidence_mode": "categorical", "confidence_weight": 0.1, "confidence_balance": 0.0}`。

原始配置与验证诊断：[模型目录](/root/pykt-toolkit/examples/saved_model/confidence_iterations_20261025/r1_categorical)。

### 第 2 轮：有序累计 BCE

同五档输出，加入等级距离；训练初始梯度匹配后权重 0.182，验证集选定。

关键配置：`{"confidence_mode": "ordinal", "confidence_weight": 0.182, "confidence_balance": 0.0}`。

原始配置与验证诊断：[模型目录](/root/pykt-toolkit/examples/saved_model/confidence_iterations_20261025/r2_ordinal)。

### 第 3 轮：正误条件联合分布

预测 P(信心|正误,历史)，改善联合 NLL，但主验证 AUC 未超过第二轮。

关键配置：`{"confidence_mode": "conditional", "confidence_weight": 0.1, "confidence_balance": 0.0}`。

原始配置与验证诊断：[模型目录](/root/pykt-toolkit/examples/saved_model/confidence_iterations_20261025/r3_conditional)。

### 第 4 轮：有序监督加平衡

按训练频率逆平方根加权；macro F1 改善，概率质量和等级误差变差。

关键配置：`{"confidence_mode": "ordinal", "confidence_weight": 0.182, "confidence_balance": 0.5}`。

原始配置与验证诊断：[模型目录](/root/pykt-toolkit/examples/saved_model/confidence_iterations_20261025/r4_balanced_ordinal)。
