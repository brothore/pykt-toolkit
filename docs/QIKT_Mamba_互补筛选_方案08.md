# 方案08：已有预测的有界互补筛选

先登记后执行，仅 CPU 预测融合，无新训练、seed复验或正式测试读取。数据集 nips_task34、QIKT-Mamba、fold0、seed42，基线固定原模型。B1R2 的单 seed 点结果满足开发候选条件，但 seed43/44 复验失败；这一局限保留，当前只搜索大概可行的互补预测方案，不称稳定有效。

B1R2 主要保住总体表现；A1R1/A2R2/A3R2 在某些均衡指标上改善但总体下降。假设：少量引入后三者的排序变化，可以保留 B1R2 的总体优势并改善序列均衡。互补性尚未验证，均值平均不保证 AUC改善。

F1、F2、F3 分别固定组合 B1R2+A1R1、B1R2+A2R2、B1R2+A3R2，每方向按第二个模型权重 .05、.1、.2 最多三轮，其余权重给 B1R2。所有比较均相对原基线，而不是相对 B1。每方向首个 exploratory_candidate_pass 立即记录并停止，不自动追加复验。该条件和前批保持一致，不因接近零的小幅退化而放宽。

严格对齐 orirow/qidx/标签/题目/知识点，逐轮保留标准差、极差、宏均值、pooled验证 AUC、尾部、强组、退化数量和不确定性；原权重、源码、输入数据及预测校验均落盘。正式 windowauclate_mean 未计算，明确缺失。训练元信息沿用原组件：A1R1/A2R2/A3R2/B1R2 均训练14 epoch、选中4。候选只是重复开发验证集上的线索，不是独立测试证据。
