## 1. 先区分三种“结构不变”

| 范围 | 可改变什么 | 是否符合严格“只改 loss” |
|---|---|---|
| A：严格固定学生网络 | 使用原有答对概率或已有 hidden state 计算新损失 | 是；可以为取 hidden state 扩展训练接口，但不新增网络参数 |
| B：固定推理 backbone，训练期多任务 | 在历史状态后添加时间、提示、置信度等辅助头，推理时移除 | 不是严格零新增参数；可以保持原有推理输入和主预测结构 |
| C：扩展推理模型 | 将新的行为历史、时间或其他特征直接送入模型 | 不属于当前优先考虑的范围 |

还有一种 A* 路线：学生网络严格不变，训练时额外训练/调用一个丰富历史信息的教师，增加蒸馏 loss。它保持学生结构，但增加训练阶段的网络与计算成本。

“用提示次数调整 BCE 权重”与“学习预测提示需求”是两个不同任务：前者是样本重加权，不代表模型已经具备提示行为的生成能力。

## 2. 本地数据实际有哪些信号

### 2.1 ASSIST2009：过程信号最丰富

统计口径：原始 346,860 行；按当前预处理的核心字段非空条件过滤后为 283,105 条记录、4,163 名学生，尚未删除短序列学生。

| 字段/信号 | 本地核验结果 | 目前是否进入标准 KT 序列 |
|---|---|---|
| `order_id` | 有效记录中 283,105 个唯一 ID，无重复；全部为 8 位数字 | 只用于排序，随后丢弃 |
| `attempt_count` | 非空率 100%；中位数 1，P90=2，P99=8，最大 3,824 | 否 |
| `ms_first_response` | 非空率 100%；中位数 20.263 秒，P90≈94.909 秒 | 否，标准用时被写成 `NA` |
| `hint_count` / `hint_total` | 非空率均 100%；42,519 条使用过提示 | 否 |
| `first_action` | 0/1/2 分别为 255,317 / 21,565 / 6,223 条 | 否 |
| `bottom_hint` | 42,522 条非空，覆盖 15.02%；29,045 条值为 1 | 否 |
| `template_id` | 覆盖 100%，658 个模板，其中 596 个模板对应多个题目 | 否 |
| `opportunity` | 覆盖 100%，中位数 7，P90=29 | 否 |
| `answer_type` | 5 类；主要为 algebra、choose_1、fill_in_1 | 否 |
| `answer_text` / `answer_id` | 非空率分别约 79.63% / 10.56%，覆盖依题型而异 | 否 |
| `original` | 主问题 259,399 条；脚手架问题 23,706 条 | 否 |

重要解释与质量问题：

1. 官方定义的 `correct=1` 是首次尝试正确，`correct=0` 可以表示首次尝试错误或先求助。它不是“最终是否解出”或“真实是否掌握”的直接标注。`first_action=0/1/2` 分别为尝试、提示、脚手架。
2. 本地所有 `first_action=1/2` 的记录均为 `correct=0`；提示和首次行为任务可能部分重复主标签，需要检验它们在已知正误后是否仍有额外信息。
3. 有 38,153 条 `attempt_count=1 & correct=0`；尝试次数不等于正误的简单编码。另有 9 条使用过提示但 `correct=1`，不能直接用单一规则覆盖全部日志。
4. 首次响应时间有 5 条负值、310 条零值、130 条超过一小时。时间字段完整不等于可靠，需在训练折内确定异常处理和截断规则。
5. `overlap_time` 约 68.24% 与首次响应时间相同，且有 9 条负值；官方也提示该字段存在计算问题，不作为首选精确总作答时长。
6. 本地文件 `type` 全部为 `MasterySection`，没有分类监督价值；`tutor_mode` 也几乎全为 tutor，不能假定字段存在就有足够信息。
7. 当前版本原始有效记录的 `order_id` 唯一；预处理随后会展开多知识点，复制同一次回答。新增行为目标应绑定原始事件，不应把这些 token 当成独立行为观测。
8. skill-builder 的练习结束可能由平台掌握标准触发，不能把记录停止直接标成学生放弃。

语义来源：[ASSIST2009 官方说明](https://sites.google.com/site/assistmentsdata/home/2009-2010-assistment-data)、[官方字段解释](https://sites.google.com/site/assistmentsdata/an-explanation-on-how-to-interpret-our-data-sets)。上述数量、覆盖率和异常统计来自本地文件。

### 2.2 NIPS task 3/4：选项与自报置信度值得研究

- 1,382,727 条记录，4,918 名学生、948 道题；`AnswerId` 唯一，作答元数据完整一对一匹配。
- `AnswerValue` / `CorrectAnswer` 完整，取值 1–4；`IsCorrect` 与两者是否相等完全一致。只增加一个“选项是否正确”任务不会新增信息；具体错误选项才提供更细粒度结果。
- `Confidence` 实际有 346,428 条非空，覆盖约 25.054%，取值 0/25/50/75/100；涉及 4,284 名学生和 904 道题。缺失不能填成 0，因为 0 是有效的自报置信度。
- `Confidence=100` 中有 42,621 条错误；`Confidence=0` 中有 9,616 条正确。这些是可观察的信心—表现组合，不能分别直接认定为粗心或真实猜对。
- `GroupId`、`QuizId` 完整，分别有 370、120 个不同值；`SchemeOfWorkId` 覆盖约 91.64%。可用于课程上下文、任务分配分析和分层控制。
- 时间戳均为整分钟；学生内相邻记录约 48.35% 时间相同，最小正间隔为 60 秒。因此不能把记录间隔称为逐题反应时间，也不能假定并列时间内具有真实答题顺序。
- 4 道题的 `CorrectAnswer` 跨记录不一致，涉及 5,074 条记录。可能有选项重排、版本或数据问题，原因尚未核验；不能假定每个题 ID 对应一个永不变化的正确选项位置。
- 原始题目元数据保留多层 `SubjectId`；当前处理只取第三级标签，层级结构被压缩。科目表本身有 0–3 四层和父子关系。
- 本地压缩包没有题目图片文件；不能把“官方数据可提供图片”写成“本机已具备图片监督”。

官方将 Confidence 定义为学生自报的确信程度；它不是学生真实能力或模型预测置信度的真值。task 1/2 与 task 3/4 的 ID 独立匿名化，不允许直接按 ID 混用两套数据。[数据发布方论文](https://proceedings.mlr.press/v133/wang21a/wang21a.pdf)

### 2.3 培优：标签重复，但题目内容和层级丰富

- 5,549,635 条记录，18,066 名学生、7,652 道题。
- `ans_state=1` 的 4,410,399 条全部 `label=1`，`ans_state=2` 的 1,139,236 条全部 `label=0`。这是正误的等价编码，不可当作新的行为监督任务。
- `questions.json` 覆盖全部 7,652 道题，均有非空 `content`、`analysis`、`concept_routes`；多条知识路径和多个层级可用于结构监督。
- `type` 实际为 0/1，两类都应视为已记录的代码，不能把 0 当成缺失；尚未确认具体业务语义，暂不命名为特定题型。
- `analysis` 是题目解析，不是学生的思考过程。不能用它声称已获得学生推理链或真实错因标签。
- 时间数量级和日期支持毫秒 epoch 的解释，但时区业务语义尚未确认；主体时间在 2020/2021 年，另有 2001 年 7 条、2018 年 23 条，异常或来源含义待核对。
- 学生内相邻记录约 51.60% 时间相同，不能将间隔当成每道题实际耗时。
- `(stu_id, que_id, timestamp)` 有 56,942 个重复组，其中 819 组回答标签不一致；不能按这三个字段静默去重或假定为同一次行为。后续对齐应保留原始行序号。

## 3. 新增候选方案

### S01：过程感知状态——预测耗时、尝试和求助（ASSIST，B）

**目标**：让同一个历史状态解释“能否独立首次答对、需要多少尝试、是否求助、多久作出第一反应”。这是最直接有真实过程观测的多任务方案。

- 时间目标：清洗后的 `log(1 + ms_first_response/1000)`，用 Huber/分位数回归，或预测快/中/慢区间。
- 尝试目标：0/1/2/3+ 等有序分档，优于直接回归极端计数。
- 求助目标：`hint_count>0`、提示使用强度或底部提示请求；对无提示机会、缺失和脚手架情境设单独掩码。
- 辅助头读取历史状态，以及作答前已知的目标知识点/题目上下文；目标题的真实耗时、提示与尝试不能送入主预测路径。
- 提示等与正确性高度相关，需比较只凭题目属性/主正确率的对照，并研究它在同为错误的样本内是否仍有信息。

一个特别值得比较的子方案是将当前二元标签细分为**首步行为结果**。按本地 `correct × first_action`，可构造以下四个可观察类别，而不制造心理标签：

| 类别 | 构造条件 | 本地有效记录数 |
|---|---|---:|
| 首次正确 | `correct=1, first_action=0` | 186,322 |
| 首动作尝试但首次未正确 | `correct=0, first_action=0` | 68,995 |
| 首动作请求提示 | `correct=0, first_action=1` | 21,565 |
| 首动作转入脚手架 | `correct=0, first_action=2` | 6,223 |

这让模型在训练期区分当前都被记为 0 的三种结果。可以保留主 BCE，同时增加四分类辅助 CE；不能声称四分类无需额外输出自由度。应比较相对“直接复制正误”的辅助任务，是否学到了真正的额外区分能力。

解释：它模拟的是可观察作答过程，不直接监督“焦虑、专注、粗心”。推理期可以移除辅助头；如果需要真正生成这些行为，则要保留相应头并明确推理范围已扩展。

### S02：信心—表现联合监督（NIPS，B）

**目标**：分别学习“学生认为自己有多大把握”与“实际会不会答对”。

- 在置信度非空记录上预测 5 档 Confidence 或有序分布；缺失不当作低置信度。
- 可增加高信心错误、低信心正确等联合事件目标；高低阈值需事先固定或仅用训练折确定。
- 自报信心不是正确率软标签，不能简单要求主预测概率等于 `Confidence/100`。
- 观察覆盖只有 25.1%，且报告行为可能有选择性；任务单独按有效记录归一化，报告覆盖与分组表现，不假定随机缺失。

研究问题：这个额外维度是否能帮助区分稳定掌握、信心不足和持续的高信心错误？最后一种最多提示需要进一步诊断，不等于已经标注了某种误解。

### S03：从“错了”到“选了什么”（NIPS，B）

**目标**：预测具体 `AnswerValue`，让同样的错误结果保留更多信息。

- 用四分类 CE 监督作答选项，主任务仍为原有二元回答预测。
- 必须考虑目标题目上下文；跨题的选项 1/2/3/4 没有统一的错因语义，不能只做一个无题目信息的全局字母分类器。
- 对正确选项不一致的题目，先核对是否选项重排或版本变化，不能用错误的题目级固定答案映射。
- “是否选对”本身与 `IsCorrect` 等价，不单独作为新辅助任务。
- 本机缺少图片和干扰项语义标注，所以第一阶段只能研究可观察选项模式，不能宣称识别了具体概念误解。

### S04：历史过程教师蒸馏到标准 DKT（ASSIST 优先，A*）

**目标**：利用原始数据丰富的历史信号，同时严格保留学生模型的标准输入和网络结构。

1. 教师只读取截至 `t` 已完成交互的正误、耗时、提示和尝试等历史，预测下一题。
2. 学生仍只读取原有题目/知识点与正误历史。
3. 在 BCE 外添加教师分布到学生分布的 KL 或软目标损失。

教师禁止读取目标题 `t+1` 的真实回答或其事后过程字段；否则只是把目标答案包装成教师预测。教师仅用训练折拟合，必要时生成训练学生的折外软标签，防止记忆训练样本的“神谕教师”。

这条路线保持学生结构，但有额外教师训练成本。它传递的是已有信息能够预测的丰富历史统计，不可能恢复学生输入中完全不可辨识的信息。

### S05：同知识点/同模板的后续独立表现（ASSIST 优先，A）

**目标**：相比“这一题是否对”，关注学生是否能在新的相似题上独立解决问题。

- 利用 `template_id`、知识点和 `first_action/hint_count`，寻找后续独立尝试的不同题目。
- 用当前状态已有的知识点答对概率，监督后续短窗口的独立表现，或以真实未来结果构造配对/分组损失。
- 不能强制“后一次一定比前一次更好”；学习、遗忘和题目难度都可能导致下降。
- 求助后表现改善只能称为观察到的恢复/迁移，不能自动归因于提示产生了因果学习效果。
- 跳过同一原始事件的多知识点复制；不把同模板题假定为等难度。

这条路线沿用 `L_profile`，但把原始事件和模板关系用于更有针对性的目标选择。

### S06：时间间隔分层的保持表现（NIPS / 培优，A 或 B）

**目标**：考察同一知识点在不同间隔后的再次作答表现。

- 构造后续同知识点的真实重访事件，按短/中/长间隔形成保持表现目标。
- A：用原有预测做分层加权或评估，不新增参数，但不能声称模型因此获得了显式依赖时间的预测能力。
- B：训练期增加按已给定间隔查询的辅助预测头；若主预测也要随未来间隔变化，则已经需要扩展推理输入，属于 C。
- 只对有可靠时间的记录使用；NIPS 最小粒度为分钟，培优需核对异常年份，时间并列的事件不制造伪精确顺序。
- 间隔不是该题作答时长；未观察到下一次作答不等于学生不会或遗忘。

### S07：测评块的知识画像预测（NIPS / 培优，A 优先）

**目标**：从测评块之前的状态，预测一组题的得分和分知识点表现，而非过度依赖不可靠的块内顺序。

- NIPS 可结合学生、`QuizId` 与时间形成候选块；培优只能先识别时间簇，不能凭同一时间就断言它是一场考试。
- 块内总体分数、各知识点正确率、错误数量可直接由原有概率聚合监督。
- 预测整个块时冻结块前历史，不能先读入块内部分真实答案再宣称预测了整个测评。
- 右侧不完整或多次提交的块需标记；重复题、重复时间与冲突回答先定义清楚。

### S08：知识层级上的多粒度表现监督（NIPS / 培优，A）

**目标**：同时约束细知识点、上级主题和更粗学科范围的未来表现。

- 用 NIPS 的父子科目关系、培优的 `concept_routes` 构建层级映射。
- 聚合已有叶节点答对概率，监督同一未来窗口在父级主题上的实际表现。
- 聚合应按明确的练习暴露分布加权，不把“所有子知识点概率简单平均”直接称作父知识掌握真值。
- 这是结构归纳偏置和更密集的监督，不是新增独立回答标注；避免在叶/父级反复计算同一回答造成无意放大权重。

### S09：行为画像驱动的状态对比学习（ASSIST / 有信心数据的 NIPS，A）

**目标**：让已有 hidden state 反映相近的可观察未来表现和行为风格。

- 从训练样本未来窗口构造表现、提示、时间或信心的联合描述，建立有证据的相似/不相似历史前缀。
- 对已有 hidden state 直接施加对比损失；不必新增投影网络。
- 配对需控制知识点、题目/模板和练习机会，不能把课程相同当作学生相同。
- 不自动把同一学生的任意两个时刻设为正样本，因为学生确实会变化；也不强迫“能力相似但作答风格不同”的学生完全重合。
- 未来描述只用于训练配对，不进入推理特征；有状态塌缩和课程捷径风险，优先级低于直接行为监督。

### S10：题目解析支持的语义教师（培优，A* 或 B）

**目标**：利用题目内容、知识路径和解析提供的静态结构，而不把解析当成学生自己的推理。

- 可提取所需知识层次、解题步骤结构或题目复杂性，作为历史过程教师的题目表示，或作为训练期结构辅助目标。
- 题目解析是静态内容，只能帮助刻画题目和知识关系；它没有提供学生实际上在哪一步出错的标签。
- 仅预测题目静态属性可能完全绕开学生历史，需与“只输入题目”的头做对照；不能用静态任务 loss 下降证明学生状态更好。
- 若使用外部模型生成标签，先固定标注规范并抽查，不将生成的猜测视为真实错因；本轮未进行这种生成或下载。

## 4. 统一的多任务目标与验收问题

训练期辅助目标可写为：

\[
L=L_{KT}+\sum_k\lambda_k
\frac{\sum_{i,t}m^{(k)}_{i,t}w^{(k)}_{i,t}\ell^{(k)}_{i,t}}
{\max(1,\sum_{i,t}m^{(k)}_{i,t}w^{(k)}_{i,t})}.
\]

- `m` 同时表示字段可用、事件有效和样本属于训练折；缺失与零值严格区分。
- `w` 可控制原始事件、多知识点复制、稀疏目标和可靠性；权重应明确记录，不默默改变原有主任务口径。
- 每个任务独立按有效样本归一化，不能让 25% 覆盖的信心任务因缺失被误填、或由有效条数决定隐含权重。
- 用验证集确定损失系数和时间/计数分档；不以测试 `windowauclate_mean` 反复试选目标。
- 除主指标外，辅助任务本身也要在未见过的学生上验证：时间 MAE/分位数覆盖、提示 PR-AUC、置信度预测、选项 NLL、分知识点表现误差等。
- 做“只用题目/课程上下文”和“打乱学生状态”的对照：检验辅助任务是否真的依赖学生历史。
- 辅助 loss 降低而主指标无改善，应报告负结果，不将它包装成建模收益。

## 5. 对齐、泄漏和基线隔离

1. **先按当前学生划分建立标签表**：使用 `keyid2idx.json` 映射原始学生、题目、知识点，保持 fold 和被删除短序列学生的规则。
2. **保留原始事件键**：ASSIST 用原始 `order_id`；NIPS 用 `AnswerId`；培优保留原始行序号，不只依赖学生/题目/时间三元组。
3. **不要覆盖原有序列或缓存**：将辅助字段存入新模型专属 sidecar/目录，并明确序列截断与多知识点展开后的索引对应。
4. **确认事件可见时点**：目标题真实提示、尝试、答案、信心和用时均为目标或事后信息；历史已完成事件中的这些字段，在原始系统中才可能作为未来预测的历史信息。
5. **未来目标不跨数据边界**：不跨学生、不跨训练/验证/测试，不默认跨截断窗口可见；末端缺未来记录要标记不完整/删失，不能填错误或放弃。
6. **仅在训练折拟合统计**：时间分位数、题目/模板难度、归一化、类别频率、教师和样本权重都不能用验证/测试标签估计。
7. **顺序不明确时保守处理**：时间并列不等于已知真实顺序；当前原始行序可用于复现旧基线，但不能为新时间/行为任务证明因果顺序。
8. **当前审计是全量字段可用性统计**，不是可直接用于模型的训练统计；真正实验必须重新按训练折估计目标相关阈值。

## 6. 暂不采用的捷径

- 把培优 `ans_state` 或 NIPS “选项是否正确”作为独立新标签：与主标签等价。
- 把高信心答错、快速答错、模型高概率却答错直接标成“粗心”：只能是有噪声的行为组合或候选代理。
- 用 NIPS/培优相邻时间差监督逐题反应时间：粒度和批量记录不支持这种解释。
- 将 ASSIST 最后一次记录当作退出/厌学：可能是掌握后平台停止出题，也可能只是数据截断。
- 给每名训练学生分配专有 embedding 后声称建模了新学生个性：当前测试学生未见过。
- 强制后一次概率比前一次高，或只因得到帮助就强制掌握上升：实际观测并不保证单调或因果效应。
