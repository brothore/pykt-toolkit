# DKT 测评画像与层级监督：五轮实验

日期：2026-10-27。分支：`feat/student-state-simulator`。方案 S07、S08，独立模型 `dkt_profile`。

测试前按保留检查点标准验证 AUC 选定 `r3_weight`；未来画像处理组中验证最高为 `r3_weight`，其 `windowauclate_mean` 为 0.767898870，相对原 DKT +0.000456057。匹配选定权重的第三轮真实父主题减第五轮随机分组为 +0.000135665，该差值的95%区间包含0，真实知识层级的独立额外收益尚未证实。

## 1. 只改目标函数

学生严格继承原 DKT 的 `forward(c,r)`，没有新增模块、参数或 buffer；NIPS 学生参数 **355857**。检查点和导出权重均可由原 DKT 严格加载，实际预测逐元素一致。原 `dkt.py`、数据加载器、ALSO 与 kt_config 均未修改；本次只在工厂、训练和评估路由增加新模型名。

从当前 chunk 内、测评块开始前最后一个原始事件的最后概念位置取状态 `h_a`。块内所有题目概率均从这个固定状态查询，不把块内已完成的答案回填到该状态，再声称预测整个块。LSTM 的因果性保证后续答案不影响该前缀。状态只包含**当前 chunk 前缀**，不等于完整终身历史；没有闭环 rollout 或推演中间学习。

`L = 原始逐概念 BCE + λ × 块画像辅助 BCE`。若题目 j 有去重概念集合 Cj，题目概率近似为 `sum(p_a(c),c in Cj)/|Cj|`；整块概率对题目等权平均，目标为该块平均正确率。未来题目/主题仅在 loss 中确定查询与监督曝光分布，不进入 forward。推理仍用原 DKT。

父主题采用原 metadata 中 **25 个 Level 2 直接父节点**。每条原始答题总曝光为1，在该题去重叶概念间平均分配。父主题的预测和目标按其实际练习曝光加权，父主题质量之和为1。联合版给整块总分一半质量、全部父主题合计一半质量，每个 session 总质量为1，防止叶/父层重复放大同一回答。不是对父主题所有子概念无条件平均，也不是新增心理状态真值。它重用原有正误和真实课程关系。

## 2. 测评块与原始数据审计

复用 ConfidenceDataset 的 AnswerId、时间并列原始行序和完整 q/c/r/time 核验。原始标签只涉及 train_valid 学生，训练/验证学生互斥；不用测试学生的标签构造块或拟合阈值。知识层级是静态元数据，随机分组固定 seed 20261027，不从任何标签拟合。

块定义为同学生 **QuizId＋自然日的连续观测 run**。同一 QuizId/day 非连续重访整组剔除；缺 QuizId、首段无前史、最后段右删失、单题、块内重复题、块边界时间并列、块内任一相邻间隔超过30分钟都剔除。对保留 run，还要求完整目标和块前锚点位于同一原有非重叠 chunk；多概念副本数必须完整且不当作新事件。

这是可复现的**观测测评片段**，不保证覆盖一场真实考试的完整题集。剔除末段只能保守处理尾部，不能证明所有其他 run 无缺失。30分钟、自然日、至少2题规则预先固定，未按测试分数调整。

- 原始训练/验证答题：1109911。
- 原始合格候选块：61909；完整 chunk 内可用块：59446。
- 训练47548块、验证11898块；平均分别12.2932、12.2214条原始答题。
- 实际跨多个真实父主题块：32609（54.85%）。其余块的父主题画像高度重合总分。
- 每块真实 / 随机父分组平均数量：2.1036 / 2.8064。对照保持全局各组叶概念数量，但不保证每块分组数量和曝光相同。

原始 run 剔除计数：`{"no_prior_history": 3857, "internal_gap_over_30min": 3486, "right_censored_user_tail": 3478, "noncontiguous_revisit": 46571, "singleton": 2707, "tied_session_boundary": 2205}`。跨 chunk/部分块计数为出现次数，不能当唯一块损失数。保留集偏向较短、连续、无重访的片段，不能代表所有练习分布。

独立审计直接由缓存 AnswerId 和原始题目、正误、QuizId、时间重新计算全部59446块的整块/父级/随机级曝光和目标，检查 UID/fold、严格前缀时间、多概念副本完整性、父级质量合计和唯一 row/anchor，均通过。见 [profile_audit.json](../logs/profile_iterations_20261027/profile_audit.json)。

## 3. 多轮闭环

第一轮先只监督整块总分，验证 AUC 0.762252658，略低于原 DKT 0.762496754。

第二轮加入真实父主题分项，保持每块总质量不变，验证 AUC 0.762319034。仍未超过基线，第三轮按预写规则将 λ 从0.1降低至0.03，检验辅助约束是否过强；所有块、标签和层级映射不变。这是验证驱动调整，没有查看新版本测试指标。

第四轮为预先声明的诊断对照：同样的整块总分＋父分组形式、λ0.1，但使用固定随机置换后的叶到父组映射，保持全局组大小。真实语义若有独立价值，应与匹配的第二轮比较；为直接检验选定第三轮，又增加第五轮λ0.03随机分组对照，计划在读取任何新测试指标前单独登记，两项对照均不参与选模。对照在训练前排除方案选模，测试后不将它替换为选定方案。

## 4. 固定预算与测试前冻结

NIPS task34 / fold0 / seed42 / 每轮最多20 epoch，batch32、embedding/LSTM200、dropout0.2、Adam0.001；关闭 ALSO、wandb、增强。原训练顺序、标准验证选模及 `auc > max_auc+1e-3` 保留规则、patience10 不变。保留 epoch 不一定是所有 epoch 的精确最大 AUC。

训练6043序列、验证1503序列，分别3148/787名学生。复用信心阶段同设置原 DKT 基线，不声称本次重新训练/测试基线；原验证 AUC 已重新复现。原始数据和序列哈希匹配，见 [baseline_data_checks.json](../logs/profile_iterations_20261027/baseline_data_checks.json)。

冻结时间 `2026-10-27T03:50:53.153354+00:00`，候选包含原 DKT 和前三轮；选定 `r3_weight`。原四轮检查点、画像缓存和源码哈希在新测试前冻结；新增第五轮在单独测试前再次冻结，其计划和哈希不改写原选模文件。五个新模型只运行主指标所需的原逐题窗口 late fusion，batch512 与基线一致；没有重跑其余三种测试。指标未重写。

## 6. 固定验证块的辅助表现

所有模型在完全相同的验证块、真实父主题集合上比较。MSE针对**块/父主题正确率**，不是逐题 Brier，不能与主 AUC 混用。

| 版本 | 整块分数 MSE | 真实父主题分数 MSE | 扰动历史后真实父主题 MSE |
|---|---:|---:|---:|
| 原 DKT（复用） | 0.048467674 | 0.068292716 | 0.115227168 |
| 第一轮：整块总分，λ0.1 | 0.043431484 | 0.063099682 | 0.111193040 |
| 第二轮：总分＋真实父主题，λ0.1 | 0.043480329 | 0.062029277 | 0.110587088 |
| 第三轮：总分＋真实父主题，λ0.03 | 0.046038272 | 0.065322404 | 0.113646451 |
| 第四轮：总分＋随机父分组对照，λ0.1 | 0.043688767 | 0.062306259 | 0.110895130 |
| 第五轮：总分＋随机父分组对照，λ0.03 | 0.046151159 | 0.065340995 | 0.111825774 |


第一轮整块正确率MSE从基线0.048468降到0.043431；第二轮真实父主题MSE从0.068293降到0.062029。但这两轮主测试AUC都略低于基线，说明改善群体/未来块表现预测，不保证改善下一题排序，不能把辅助目标下降直接当作KT收益。

“扰动历史”仅将同 batch 响应序列循环移位，题目与当前学生块标签保持不变，检查预测对历史正确性是否敏感。它产生分布偏移，且并非独立训练的“只用题目”对照，不能证明收益来自更真实的心理建模。辅助任务误差改善而主 AUC 不变/下降也如实保留。
