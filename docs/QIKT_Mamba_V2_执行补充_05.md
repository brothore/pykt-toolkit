## A3：有限、可恢复的风险倾斜近似

R1：每个 epoch 开始以当前模型 eval 模式遍历**训练折**，汇总完整 UID 的原生融合 BCE 与原辅助头损失，除以该 UID 的全部计分目标数。按 `exp(t*L_uid)` 单调分配权重，通过标量二分归一化，使均值为1且严格限制在 [.5,2]。原目标混合占比 .75、风险倾斜等序列项 .25，t=.5。

权重在随后整个 epoch 固定，因此这是**epoch-lagged TERM-inspired 近似**，不是在线精确 TERM。额外风险测量不更新参数，并恢复 Python/NumPy/Torch/CUDA 及 DataLoader/sampler 随机状态；不得把额外数据遍历隐藏在成本报告外。

R2：预先固定 t=.25，其他设置不变，作为保守的倾斜强度消融；不把未证实的“噪声主导”当作事实。Group-DRO/OOF 困难权重不在本批实施，需另有支持充分的训练群体和合规 OOF 证据后登记。

每个 epoch 保存 UID 风险、权重与测量耗时；完整 epoch 检查点恢复后重新确定下一 epoch 权重。实际 QIKT 的连续/断点训练参数与权重序列一致性需先通过测试。

## C1：有界分支与已正确排序的保护

复用 B2 的冻结基线、16维条件化分支，投影保持冻结，logit 修正上限 .05。仅对训练标签定义的、教师 `p_positive-p_negative>.1` 的同片段正负对惩罚学生缩小已有概率差；系数固定1，保留原 BCE 与 KL。

R1：KL=1，seed42。R2：若 R1 全部开发候选条件通过，用相同参数复验 seed43；否则若高分组均值下降则 KL=2，未下降则 KL=.1，仍用 seed42。只改变 KL 或复验种子，排序保护系数与模型结构保持不变。

教师在训练折拟合，属于 in-sample 教师，不冒称 OOF。高置信正负对在很小有界修正下本就较难翻转；这里额外保护的是概率差，而不只是顺序。低 margin 对、跨序列对和每条序列 AUC 仍无保证。

## C2：先固定融合，后审计学习型路由前提

预登记固定 .5/.5 的比较：基线+B1R2、基线+B2R1、基线+C1R1、B1R2+B2R1。仅用验证预测，系数不根据结果调整；B1 复验失败也必须保留披露。逐个保存尾部、标准差、极差和退化指标。

学习型前缀 gate 必须有排除外层 fold0、且其预测行没有参与教师梯度训练/选模的 OOF 数据。当前并无该证据。本批 R2 是前置审计，若条件不足记录 `not_run_missing_oof`，不训练 gate，不将审计完成称为学习型方案成功。即使发现文件也须复核其折分与来源，不盲目启动尚未验证的训练实现。
