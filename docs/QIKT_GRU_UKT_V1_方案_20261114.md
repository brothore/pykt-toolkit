# 双GRU基线上的UKT机制迁移：V1

用户2026-11-14要求停止旧Mamba方向，改为题目与知识点两个独立GRU分支，先研究UKT。旧队列已全部终止，无需向不存在的训练发送停止信号；历史结果封存，不继续旧参数搜索。

## 证据与边界

指定七模型报告是正式测试集事后分析：NIPS主子集967条、Peiyou3605条，不能与此前nips fold0开发验证的773条混同。只用其提出假设，不按测试orirow、完整正确率或真实AUC训练/路由。新方案参数选择与早停仍在训练折与fold0开发验证进行；正式测试后置。

UKT现有NIPS配置seed3407、28 epoch、正式windowauclate_mean=.801124108957146，序列宏AUC=.7221599420230015、std=.08958305540036236、range=.5431285058643549；仅是现有配置描述。它并非七模型中整体或弱组最优，不能先验称UKT机制有用。Peiyou同样不是整体最优，需区分局部优势与可迁移性。

实际UKT配置use_CL=0、atten_type=w2、stoc_qid，启用均值/对角协方差表示、Wasserstein检索、题目Rasch调制与距离相关衰减；对比学习与响应增强没有进入该训练目标。源码用平方注意力权重传播协方差，不等于简单概率置信度。距离乘性调制作用于负距离分数，不能直接解释为“越远权重越小”。需以代码和消融判断，不照搬名称。

## 基线B0

先训练B0、导出原生验证片段与窗口预测，作为所有新方案共同参照。B0正式windowauclate_mean尚未产生；报告开发窗口AUC不得改名。

## 首批迁移与匹配对照

当前题条件下严格检索过去题目/响应；保留双GRU状态路径，再用有界零初始化补充分支融合到原输出。不是将GRU替换为UKT。各轮都从同seed重新初始化整模型，旧Mamba补充分支不自动带入。

|方向|改变|要回答的问题|
|---|---|---|
|R0|均值距离检索，固定单位协方差，加入有界logit补充|普通相关历史读出本身是否有用，作为W2对照|
|R1|学习均值/正协方差，用对角Wasserstein距离；值均值按alpha、协方差按alpha²聚合|不确定性表示与检索是否比R0有增量|
|R2|R1，融合修正再除以1+检索协方差均值|不确定性用于控制修正强度，是否降低对强项的损害|
|R3|R1加入UKT现有乘性距离调制|现有UKT衰减设计是否必要或有副作用|

先完成新模块因果/padding/数值与零输出一致性检查、真实32训练片段CUDA一步预检，再运行。R0/R1同轮固定scale=.1/.25/.5；R2/R3沿用同强度，每方向最多3轮，首个普通联合候选记录暂停。控制额外容量与初始化RNG，仍需注明协方差参数量不同，单seed不能做严格因果归因。题目Rasch与对比学习暂不叠加，依据本批/UKT消融证据再决定。

另对已训练UKT做验证集只读推理干预（完整模型、dot-product替换W2、去距离调制等），用于敏感性定位；不是重新训练消融，不拿其正式测试差值选参数。必要时再登记匹配训练消融。UKT源库device修复差异先核对，不能混用两个实现的权重加载结论。
