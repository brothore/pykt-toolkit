# V10：严格前缀预测残差记忆

2026-11-09，比较前登记，独立CPU筛选。此前的KC历史特征主要记录“答对多少”，没有直接记录“原模型在这个人的哪些题上持续高估或低估”。V8显示多个seed的总体提升仍不能补足共同弱项；V9固定性能锚＋均衡组件最多获得微小点候选，未达到实质门槛。因此测试新的信息机制：只用已经观察到的历史预测误差，纠正当前题的条件性偏差。

## 算法与严格因果边界

冻结原seed42 baseline。每个orirow独立维护最多过去200个**已计分位置**的状态，不使用位置0（没有其原预测）。当前位置先预测、后读取其真实响应更新状态。过去位置j记录冻结原模型p_j、误差e_j=y_j−p_j、Fisher量v_j=p_j(1−p_j)、KC和五个等宽概率桶之一。

当前条件的修正d=sum(e)/(sum(v)+λ)，裁到±radius，输出sigmoid(logit(p_current)+d)。多KC先对每个KC的修正等权平均并去重；混合模式平均两个修正再统一裁剪。不计算完整序列真实AUC，不按其选择专家，不拟合验证权重。

|方向|使用什么前缀状态|目的|
|---|---|---|
|R0|全局过去误差/Fisher|时间变化校准对照；固定统一偏置不会改变序列AUC，但随前缀变化的偏置可能改变|
|R1|当前KC各自过去误差/Fisher|定位模型对当前KC的个体化系统偏差|
|R2|当前冻结概率桶的过去误差/Fisher|检查模型在该序列的难易排序或置信区间是否有系统偏差|
|R3|KC修正与概率桶修正各.5|两类偏差是否互补|
|R4|当前KC×当前概率桶的联合过去误差/Fisher|更局部条件偏差；支持更少，存在噪声风险|

每方向最多3轮：R1 λ=3/radius=.5，R2 λ=1/radius=1，R3 λ=10/radius=1；首次普通联合点候选记录暂停。最多15次CPU比较，不新增模型训练、seed或测试推理。轮次R1/R2/R3和方向R0–R4分别是轮次编号和方法编号，报告应写“方向/roundN”避免混淆。

这是固定的前缀状态更新算法；不是对整条验证序列进行离线拟合。当前标签只在输出当前预测后加入状态，与KT读取过去响应的可用信息一致。原预测p_j来自当时最多200上下文；保留200个过去预测误差形成额外流式记忆，间接信息范围可超过当前原模型输入窗口，**不称上下文严格匹配的对照**。部署需要按序列维护状态，不能把独立窗口无状态调用冒称相同算法。

仅开发验证：nips_task34/QIKT-Mamba baseline seed42/fold0，原模型训练14 epoch、选中4；新算法无额外离线训练。primary773、ddof=0。目标仍是std与range各降≥1%、std配对95%区间上界<0且总体/宏均值、弱10/20%、自身尾10/20%、强25%均值保持；报告退化数及最差幅度。正式windowauclate_mean未取得，未完成流式正式预测脚本接入，不将本筛选伪装成原静态窗口脚本输出。

先验证当前/未来标签不影响当前及过去输出、不同UID状态隔离、窗口淘汰和去重KC、零/常数误差行为。之后用已有原生窗口预测做严格prequential重算，逐事件对齐，不接触测试。若发现开发候选，记录后暂停；正式接入需冻结规则并验证逐位置状态顺序，稳定性后置。
