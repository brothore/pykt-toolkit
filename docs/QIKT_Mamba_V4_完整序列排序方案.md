# V4：完整训练序列排序与有界风险关注

登记于正式GPU实验前。CPU数学/采样正确性原型已检查，没有V4训练收益结果。V3已完成的21条结果不回写。

## 为什么改变研究环节

V3题目修正、温和覆盖及其组合仍主要提供微小收益；P1第三轮总体/均值/std改善但range扩大，P2弱排序没有稳定补救。重叠历史持续提高总体但std扩大。继续同配方无界微调系数不足以回答机制问题。

V2/V3的序列等权是完整orirow归约，但排序只包含同切片正负对。当前原生训练5982切片来自3148条训练序列，单UID最多5片。因此可将同一UID的所有**既有计分片段**聚合在一个batch，直接比较跨片段的正负位置。模型仍在各片内做因果预测，不引入当前答案作为输入，不把被预处理丢弃的尾部补造回来，也不把聚合排序称为模型获得了无限历史。

统一假设：与其用BCE高低代替排序缺口，不如直接优化完整训练覆盖上的序列内排序；同时用有界平滑风险避免极大错序logit独占梯度，用训练正负类别支持约束不可靠的小样本波动。类别支持只代表统计支持，不保证标签无噪声或缺口可弥补。在线困难权重来自当前训练模型的排序风险，不是OOF教师或按验证AUC选弱序列。

## 公共配置与对照

nips_task34/QIKT-Mamba/public_mamba/fold0/seed42。原生优化器/选模/早停保持；基础多头BCE保留，不加KL教师保护、不加入低频或题目残差，以区分新机制。按UID随机分组，每batch16个UID，包含每个UID全部原计分切片；名义原配置batch32不代表实际切片数恒为32。30个随机epoch的离线分组观察最大44片，仅是观察；保守绝对上界16×5=80片，资源预算按上界评估。此负载不同于固定32片基准，先以保守单任务执行并记录实际吞吐/峰值，不直接宣称已校准为相同负载最优。

所有排序项先对完整UID内正负对平均，再以固定的“每epoch batch数/可排序训练UID数”归一，使epoch内无梯度变化时的均值与训练序列宏风险一致。单类别序列仍贡献原BCE，不参加排序。支持重加权及在线关注的版本有意改变等权，单独标识。

|方向|实际改变|有界预设轮次|要区分的作用|
|---|---|---|---|
|Q0|仅完整UID分组，原损失不变|1轮，rank=0|数据分组/随机轨迹变化本身|
|Q1|完整UID logistic正负排序|rank=.002/.01/.03|补齐跨切片配对；仍保留大错序梯度|
|Q2|完整UID平滑AUC风险：sigmoid((负logit−正logit)/.5)|rank=.03/.1/.3|有界风险，梯度更集中于可移动的排序边界|
|Q3|Q2＋训练类别支持重加权|同Q2；support_strength=5，focus=0|减少极少数类别支持的影响|
|Q4|Q3＋当前训练排序风险的温和关注|同Q2；support_strength=5，focus=1|在有支持的序列间略偏向高排序风险|

Q2/Q3/Q4同轮系数完全匹配；Q1不同损失尺度，不能把它与Q2的系数数值相等误当作有效强度相等。支持权重为minority/(minority+5)，在可排序训练UID中归一；关注权重exp(focus×(当前平滑风险−.5))裁到[.75,1.25]，停止梯度；两者乘积总权重裁到[.25,1.5]。这是在线有界排序风险近似，不声称精确TERM或可靠困难OOF。

每方向最多3轮，Q0仅1轮，共最多13轮。初步候选即记录暂停，不自动追加seed/fold/Peiyou；多方向集中比较后再决定稳定性。Q0不可省略，否则不能将分组变化全归因于新目标。
