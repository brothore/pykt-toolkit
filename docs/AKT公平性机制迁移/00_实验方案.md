# AKT 公平性机制迁移 V1

本批先建立原生 AKT 匹配基线，再检验 UKT、MTKT、LEFOKT-AKT 的设计能否改善 AKT 的序列表现均衡。来源模块只有不同程度的探索证据，不预设它们都能迁移成功。原 GRU 实验结果保持封存。

## 数据与基线

- nips_task34，fold0，seed3407。超参数来源：`/data/pykt-toolkit-latest/local_runs/best_params_20261104/akt.csv` 对应行。
- d_model=64，n_blocks=4，num_attn_heads=4，d_ff=64，dropout=0.3，Adam 学习率0.001。原 AKT Rasch 正则 l2=1e-5。
- CSV 没有指定 batch size；本批所有实验统一为64，并明确这与通用配置默认256不同，不宣称完全复现历史训练。上限200 epoch，沿用原验证展开交互 AUC 选模：提升超过0.001时保存，10轮无此提升早停。顺序采样、无 AMP/调度器/增广。
- 训练使用原生展开概念片段；各模型使用完全相同的输入、目标、优化器、选模和早停规则。概念展开原生训练可能包含同题多个 KC 的标签关联，本批并未修复这一共同训练语义；主要评估严格隔离当前整题的所有标签。
- 开发评估：每个题目目标独立查询其各 KC，然后均值融合，最多199个历史展开概念加当前目标；与旧双GRU的200题上下文不同，不能混称相同信息预算。

## 方案与有界迭代

| 编号 | 来源与改动 | 第一轮 / 后续两轮 scale | 关键解释 |
|---|---|---|---|
| B0 | 原始 AKT | 无 | 直接实例化原 AKT，不增加模块 |
| U | UKT 协方差历史匹配 | 0.1 / 0.3 / 1.0 | 当前题无标签表示查询历史交互，正对角协方差参与 Wasserstein 距离，alpha² 聚合后残差补充 AKT；简化迁移，非完整 UKT |
| M-C | MTKT CIC | 0.1 / 0.3 / 1.0 | 对 AKT 已有因果隐状态进行双卷积门控融合，以零初始化输出残差接入 |
| M-T | MTKT 时间设计 | 0.1 / 0.5 / 1.0 | 复用重复间隔、相邻间隔、历史次数桶，经过小型解码修正；不迁入完整时间Transformer |
| L | LEFOKT 加性替代 | 0.1 / 0.03 / 0.3 | AKT 本身已有 Rasch，因此保留原 PID、KC、response 参数，用零原点加性表达替换双侧乘法，不重复添加 Rasch |

每个方向最多三轮。任一轮满足下述初步候选条件，则记录该方向并暂停余下轮次。不自动扩 seed、fold 或 peiyou；本批最多13个训练（含baseline），实际数量可因提前找到候选减少。暂不组合多个来源，以免单独机制贡献无法区分。

## 指标与候选条件

主开发子集是 orirow 内目标数至少20且两类较少类至少5的序列，预期773条，执行时核查真实数量。报告题目 pooled AUC、序列宏平均、标准差 ddof=0、极差、5%–95%跨度、自身和固定基线最弱10%/20%、固定最强25%、逐序列退化数量及阈值、端点变化和配对 bootstrap 区间。

初步候选要求：标准差和极差均降低，pooled/macro、自身尾部、基线固定弱序列与强序列群体均值均不下降。逐序列零退化另列严格条件，不以群体均值保护代替。实质幅度参考为标准差至少缩减1%、极差至少缩减2%，只作探索分级，单 seed 不构成稳定性或显著性证明。500次 orirow 重采样区间不替代跨 seed 复验，不把多次验证筛选后的区间当确认性检验。

正式 `all_results.json.windowauclate_mean` 与开发严格题目 AUC 是不同链路。当前第一阶段只用开发数据调参；正式测试不参与候选选择，缺失字段明确标缺失，不用开发数值替代。完整结果汇总见同目录 `01_结果汇总.md`。

时间机制使用数据中的事件时间（来源 DateAnswered），当前目标时间可用是额外假设，不据此声称答题前部署有效。非时间方案不输入时间特征。

## 执行与追溯

新任务使用独立 tsp 队列 `/tmp/pykt-akt-mechanism-20261115.sock`，先基线，再四个独立方向。GPU 按真实 AKT batch64 的同步起跑单/双并发等工作量吞吐测量选择；此结论不自动推广到窗口推理或其他模型。容器总计费、冷净缓存折半后的保守余量及 GPU 峰值共同决定准入，至少保留6GiB保守内存余量与6GiB显存余量，最多双并发。

每轮输出完整配置、源码/数据 SHA256、Git提交、环境、任务ID/tspID、命令、PID、阶段状态、起止时间、逐epoch吞吐、优化器/RNG/选模/早停检查点、预测分片与最终逐序列结果。训练在完整epoch边界响应 SIGTERM/SIGINT；未提交epoch恢复时重放，不称逐step精确续训。评估在预测批次边界续做，身份不符拒绝覆盖。所有产物位于 `/data/pykt-toolkit-archive/akt_mechanism_v1_20261115/`，仓库 logs 同名软链接，不提交权重、数据或日志。
